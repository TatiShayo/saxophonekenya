# SaxophoneKenya — Luxury Saxophone Artist Portfolio

Official luxury portfolio and booking website for **Frederic Sax Ke** (Fredrick Ogonda Odundo) — premier luxury saxophonist in Nairobi, Kenya.

Live Sax performance booking for luxury weddings, galas, corporate events, and live stages across Kenya.

## Features & Highlights
- **Luxury Obsidian & Camel Design System**: High-end typography with Cinzel, Plus Jakarta Sans, and JetBrains Mono.
- **Embedded Showcase Videos & Audio**: Featuring signature performances, wedding sets, and live festival stages.
- **Interactive Rate Card & Services**: Dedicated booking tiers, packages, and FAQ.
- **Direct WhatsApp & Phone Booking Integration**: Seamless client inquiries.
- **Vercel & Static Hosting Ready**: Optimized caching headers and routing via `vercel.json`.

## Deployment
Configured for instant deployment on [Vercel](https://vercel.com):
```bash
vercel --prod
```
